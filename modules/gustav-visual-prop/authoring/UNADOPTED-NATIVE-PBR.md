# Unadopted native material experiment
The user confirmed on 2026-10-10 that this generator should use PGF materials rather than a separate Blender material workflow. native-finish.mjs and assets/blender-native-pbr.mjs are not imported by the active generator. Eighteen real baked PNGs, native source, scripts, MCP receipt, pixel provenance and the experimental version 1.2.0 GLB are retained as an unadopted experiment. The active version 1.1.2 restores the frozen G4 PGF material path and refines only geometry.
The first G6 short MCP invocation accidentally reran the old nine-part script after a local preparation failed on a delta-snapshot file lookup. Its receipt is authentic but not evidence of the intended new geometry. The corrected script and G6-geometry-retry receipt are the adopted source.
