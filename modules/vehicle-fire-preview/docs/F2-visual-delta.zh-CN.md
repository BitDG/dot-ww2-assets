# F2 古斯塔夫烟云视觉修正

## 修正基线

F1 在统一 PGF / Firefox 的固定艺术时间 2 秒画面中，炮口烟云表现为小而均匀的软球。功能检查通过不能替代此项视觉验收。F1 源码和 D4 宿主检查点保留，不覆盖历史证据。

已观看的 Periscope 40884 铁路炮片段支持的可见特征，是局部短亮部后出现较厚、边缘多瓣的烟云，随后扩开并部分遮挡长筒。该片为多机位剪辑，目录归属不代表每个镜头均独立确证；不能据此推导真实射击时序、回动、性能或精确体量。黑白片不直接证明颜色。来源与观察限制见同目录研究说明。

## 本次改动

- 同一个艺术演出提示生成三组相互重叠、偏移的烟云层，增加不规则轮廓和浓淡层次
- 三层从同一视觉锚点出生，再随生长平滑打开；连续实录发现的“空中三团直接出现”问题已修正，不能只靠中段定帧验收
- 仅第一层有短暂亮部和局部光源，三层不表示三次真实开火
- 在自有临时 FX 根节点扩大视觉体量；所有值是画面构图设置，没有真实尺寸或时间标定
- 沿用 PGF 体积粒子 shader、烟雾池、seed 和固定步长；共享 FX 与原模型源均未修改
- API、唯一宿主 tick、移动/开火分别控制、静态 GLB 输出与资源所有权契约保持一致

## 验证边界

Node 测试使用真实生成器、AssetIR、Three 和 PGF FX，Canvas/纹理解码使用测试替身。10 项测试覆盖一提示三层、出生同点、144 个固定步长的偏移连续性、单个短亮部、seed 重播、暂停、seek、清理和静态 GLB 字节一致，但不证明 GPU 或最终画面。

偏移只作用于本模块自有 FX 根节点中新产生的 PGF Group。绑定依据为已校验 SHA 的 `tank-shot-effects.mjs` 当前返回层级，不触碰原资产。reset、演出结束、dispose 都释放偏移引用，PGF 自身继续拥有粒子与材质池的回收。

最终画面必须另用实际 Firefox 同机位 2 秒帧和连续播放实录审核，并重新执行统一宿主功能回归。原生截图、时钟证明、实录及最终状态见本模块 evidence 和 receipt；不把第三方影片或研究抽帧加入交付。

确定性承诺仅限固定模型姿态。移动与开火同时播放时，出生点在宿主帧中采样，跨帧分块严格一致性没有承诺。预览不含弹体飞行、机械回动或真实操作机制。
